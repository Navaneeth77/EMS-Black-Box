# EMS Black Box - simulation
# Target: Python 3.11  (see docs/ENVIRONMENT.md)
#
# This file is the single source of truth for the simulation package's runtime
# dependencies: pyproject.toml reads it through `[tool.setuptools.dynamic]`
# rather than restating the list. Comments therefore go on their own line —
# setuptools passes a trailing comment through into the requirement string,
# where it is a syntax error.
#
# NOTE: traci and sumolib are NOT listed here. They ship inside the SUMO
# installation (SUMO_HOME/tools) and must match the installed SUMO version
# exactly. Pinning a PyPI copy invites a version skew that shows up as
# confusing TraCI protocol errors. ems_sim.runner.sumo_env resolves the path
# at runtime instead.
