# Archive

Nothing here is deleted, superseded or wrong-by-default. These are the working
records of how the project got to where it is: the phase reports, the review
log, and the results as they were reported at the time.

They are in `archive/` because the front of the repository should answer "what is
this, what did it find, and what can I not conclude from it" in four documents,
not twenty-five. These are the twenty-five.

| Document | What it is |
|---|---|
| [`COUNCIL_LOG.md`](COUNCIL_LOG.md) | Every make/review cycle, the defect each one found, and what changed. The project's audit trail. |
| [`FINAL_RESULTS.md`](FINAL_RESULTS.md) | The Phase 5 results **as first reported**. Kept verbatim. Where the 2026-09-14 audit changed a number, [`../RESULTS.md`](../RESULTS.md) says so and this file shows what it said before. |
| [`FINAL_RND_REPORT.md`](FINAL_RND_REPORT.md) | The long-form R&D report: every experiment, control and caveat. |
| [`FINAL_VALIDATION.md`](FINAL_VALIDATION.md) | The validation gate run at the end of Phase 5. |
| [`PHASE5A_CONTROL.md`](PHASE5A_CONTROL.md) | The ambulance-free control that established the traffic-side metric is not attributable to the ambulance. |
| [`3D_READINESS.md`](3D_READINESS.md) | The gate the 3D work had to pass before it was allowed to exist. |
| [`ROADMAP.md`](ROADMAP.md) | The phase plan the project was built against. |

If a number in the archive disagrees with one in `docs/RESULTS.md`, the archive
is what was believed then and `RESULTS.md` is what is believed now, with the
reason for the change stated there.
